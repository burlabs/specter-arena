# FP-18 requirements: Work and XP read correctness

One session, one design, two PRs. PR-A (this folder's first commit) adds the update-ordered, lighter work list read, the paged XP summary read, migration 0008 and their contracts, all as additive query modes: `GET /api/work` and `GET /api/xp` without `view` return the v1 bodies unchanged. PR-B switches the arena and the Work tab to the new reads, walks every XP page, freezes the contracts and records the before and after numbers; it adds its own rows below.

Closes known limitations KL-09 (an item created long ago and accepted today can miss the arena's one accepted page) and KL-11 (`GET /api/xp` stops at 500 bindings), and removes the full-item payload from each poll (decisions, review and evidence revision are read for the item a screen opens, not for every row).

## Requirements (PR-A)

|---|---|---|
