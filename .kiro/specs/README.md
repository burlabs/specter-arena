# Feature specs

Each planned feature session adds a folder here named after its session, for example `.kiro/specs/fp-01-crew-integration-probe/`, holding that feature's requirements, design, and tasks.

FP-00 adds no feature spec: it builds tooling only. Its planning artifacts were kept local to the planning session. The first spec is `fp-01-crew-integration-probe/`; the second is `fp-02-03-contracts-and-observation/`; the third is `fp-04-bot-roster/`; the fourth is `fp-06-07-summoning-visuals/`; the fifth is `fp-08-09-work-encounters-xp/`; the sixth is `fp-10-11-live-arena/`; the seventh is `fp-16-heroes-parity/`; the eighth is `fp-17-specters-collection/`; the ninth is `fp-18-work-xp-read-correctness/`.

`spec/index.md` is the top-level index that links each spec folder once it exists.
