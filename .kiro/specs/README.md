# Feature specs

Each planned feature session adds a folder here named after its session, for example `.kiro/specs/fp-01-crew-integration-probe/`, holding that feature's requirements, design, and tasks.

FP-00 adds no feature spec: it builds tooling only. Its planning artifacts were kept local to the planning session. The first spec is `fp-01-crew-integration-probe/`.

`spec/index.md` is the top-level index that links each spec folder once it exists.
