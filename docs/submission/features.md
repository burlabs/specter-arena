## What it is

Specter Arena is a Kiro Crew app. It watches the Kiro Crew bots you choose, lets you give each one a named Specter (you pick one, or the app picks at random), turns the work it observes into XP automatically, and shows the result in a small read-only arena with an evidence inspector. XP reflects observed activity. It does not check that the outcome was right, and no person accepts anything. It runs inside your own Kiro Crew; there is no hosted version (`docs/release/judge-access.md`).

Category line for the form: Costume Contest, with the Best Kiro Crew App bonus (Eric's choice in the form).

## Features by tab

The app has four tabs, in this order: Arena, Roster, Specters and Data (`ui/src/observatory/ObservatoryPage.tsx`). It opens on the Arena. In Crew's sidebar it shows the Specter Arena logo, selected and unselected, instead of the default box. That icon behaviour is read from the Crew 0.13.0 source and is checked in the RC-4 sitting (`docs/compatibility/crew-0.13.0.md`).

## What it does not do

- No tokens or session length become XP. Only a task that ended cleanly, as observed by the app, does.
- No person accepts or rejects work. There is no Work tab. XP reflects observed activity, not whether the outcome was right.
- No "Blocked" bot state. Crew sends no lasting blocked signal, so the roster legend says "Not observable yet". "Waiting on you" is shown from Crew's flags, which were read from source and not live-tested (KL-21).
- The arena cannot decide or write anything. Minion size, hero places on the map, and the back-and-forth of a fight are presentation only.
- No numeric health, percentage or rating anywhere.
- It cannot open one bot's chat or approve a tool action. Crew has no route an app can use for that (`docs/compatibility/handoff-routes.md`).
- It does not install or assign a Crew avatar pack. Crew allows that only from your own dashboard, so the app only links to the packs, which are repository files and not part of the release artifact.
- No replay. No search, filter or sort of the heroes: the Specters tab shows the 11 fixed heroes, and the Roster searches bots by name.

## Not yet verified live

In Crew's app Library the app has a store page with a hero banner, six highlights, two use cases, a short configuration note and four screenshots of the FIXTURE preview with demo data (`app.json` listing fields, `store/`). That page has not been seen in a running Crew yet (KL-33). The assignment dialog is centred by the app's own CSS because Crew's global reset removes the browser's default centring.

The "Open Bots in Crew" click has been read statically, not clicked live (issue #124). The assignment walkthrough, the showcase, lane placement, the two-way fights and the automatic credit of a real worker run have run only on the FIXTURE preview until the RC-4 sitting and the RC-6 re-check record them. See `known-limitations.md`.
